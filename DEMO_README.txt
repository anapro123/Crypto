DEMO MODE
=========
If the scanner shows 0 opportunities (normal for real markets), run:

    python demo.py

This will populate the dashboard with realistic fake data so you can
test the UI and see how it looks when arbitrage is found.

To run the REAL scanner:

    python main.py

NOTE: Real arbitrage opportunities are rare and last only seconds.
You may need to wait several minutes or hours to see real data.
